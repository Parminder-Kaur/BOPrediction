# BOPrediction
Box office Prediction based on Linear Regression model.

Developed a predictive analytics tool using Linear Regression to estimate global box office revenue for Sci-Fi cinema. By analyzing the interaction between production budgets and early audience sentiment metrics, the model isolates key financial indicators to help studios forecast ROI before a film hits theaters.

The data was collected from kaggle
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
